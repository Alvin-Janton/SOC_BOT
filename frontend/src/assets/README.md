# Google sign-in artwork

`google-signin-icon.png` is the unmodified 2x Light / Square / no-text Android+Web
icon from Google's [pre-approved sign-in asset bundle](https://developers.google.com/static/identity/images/signin-assets.zip),
downloaded November 6, 2026. It is bundled locally and displayed at 40 × 40 CSS pixels.

Google retains its trademark/brand rights; use follows its
[Sign in with Google branding guidelines](https://developers.google.com/identity/branding-guidelines).
This attribution does not relicense the Google mark under the application code's license.
No Google script, SDK, external font or remote image is loaded by the frontend.
